# OG fonts

Static OFL font instances used by the Open Graph images (Satori needs static fonts):

- Fraunces_72pt-SemiBold.ttf
- Fraunces_72pt-SemiBoldItalic.ttf
- InstrumentSans-Medium.ttf

Take them from the `static/` folders of the Google Fonts family downloads (SIL OFL 1.1).
If a file is missing, the images render with the built-in font instead; the build never fails.
